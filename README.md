# Health Checklist Program

A web-based wellness and habit tracking application built using Google Apps Script and Google Sheets.

## Current Features

- Morning / Midday / Evening tracking flows
- Dynamic task loading
- Task mapping system
- Duplicate submission prevention
- Dark mode / light mode
- Mobile responsive layout
- Progress tracking
- Date-based submissions
- Next-period task guidance
- Google Sheets integration

## Tech Stack

- Google Apps Script
- HTML
- CSS
- JavaScript
- Google Sheets
